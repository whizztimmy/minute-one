# Minute One

A playable TikTok Shop support shift. One static page, no dependencies, no build step.

The rules come from a Customer Support Specialist job post: one-minute first reply, 30 open tickets at most, 24-hour follow-ups, and no engineering ticket without shop, shop ID, contact, issue, page and reproduction steps.

- **Run on autopilot** plays a 13-ticket shift in about 45 seconds.
- **Take the seat** gives you the same shift on a real 60-second clock.
- **Paste any ticket** to see it triaged, gated and drafted live.

Everything runs in the browser. Pasted text is never sent or stored anywhere.

To run it locally, open `index.html`.

Unofficial project by Timothy Adetunji, made for a job application. Not affiliated with Reacher or TikTok. All shops, people, IDs and tickets are invented.
